Computer Science Project

SORTNEXUS AI

Visualize. Analyze. Understand. — An interactive, fully offline laboratory for exploring how ten classic sorting algorithms work, step by step.

“SORTNEXUS AI” is the project brand name. The application does not use machine learning; every number shown comes from real algorithm execution.

Problem Statement

Sorting algorithms are taught with static diagrams and pseudocode, which hide the dynamic behavior that makes each algorithm different. Students struggle to see why Quick Sort is usually fast but sometimes slow, why Merge Sort needs extra memory, or how non-comparison sorts like Radix Sort avoid comparisons altogether.

Objective

  • Animate every comparison, swap and write of ten sorting algorithms.
  • Let users control the pace: start, pause, resume, step and reset.
  • Compare algorithms side by side on identical input.
  • Collect real performance metrics and export them for reports.
  • Provide presentation-ready explanations for each algorithm.

Technologies Used

HTML5CSS3Vanilla JavaScript (ES6+)Canvas 2D APIWeb Audio APIrequestAnimationFrameBlob / CSV exportlocalStorage

No frameworks, no server, no database, no API keys and no internet connection required.

System Architecture

Algorithm Engine10 instrumented sorts emit an operation log (compare, swap, write, read, mark)
→
Step RecorderCounts operations and verifies the final output is correctly sorted
→
Playback ControllerFrame-timed player with pause, resume, step, speed and run-ID guards
→
RenderersCanvas bars, live metrics, charts, sound synthesizer

A separate Benchmark Runner executes each algorithm without animation, repeating runs to measure average CPU time, and feeds the Analytics charts, table and CSV export.

Features

  • 10 algorithms with accurate step-level animation
  • Ascending / descending order, 5 data patterns, custom input
  • Live comparisons, swaps, writes, timing and progress
  • Side-by-side Algorithm Battle
  • Benchmark charts, comparison table and CSV export
  • Optional synthesized sound, keyboard shortcuts
  • Responsive layout and reduced-motion support

Applications

  • Classroom teaching and lab demonstrations
  • Self-study and interview preparation
  • Comparing algorithm behavior on different data shapes
  • Generating data for algorithm-analysis reports

Future Scope

  • More algorithms: Tim Sort, Intro Sort, Cocktail Shaker, Comb Sort
  • Code panel highlighting the active pseudocode line
  • Quiz mode that asks users to predict the next step
  • Recording animations as video or GIF
  • Searching and graph algorithm visualizers

Conclusion

SORTNEXUS AI turns abstract complexity notation into something visible and measurable. By watching operations happen and comparing real counts on identical inputs, learners connect theory (O(n²) vs O(n log n), stability, extra memory) to actual behavior — all inside a single offline web page.
